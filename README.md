# HT3 - Login JavaFX
 
Proyecto de Hoja de Trabajo 3, Cuarto Informática.
 
## Descripción
Módulo de autenticación (login) desarrollado en JavaFX con conexión a base de datos MySQL.
 
## Roles de usuario
- admin
- empleado
- cajero
 
## Tecnologías
- Java
- JavaFX (FXML)
- MySQL
 
## Cómo ejecutar
1. Configurar la base de datos con el script `script_bd.sql`
2. Ajustar las credenciales de conexión en `Conexion.java`
3. Ejecutar `Principal.java`
 
## Configuración de ejecución (VM Options)
 
Este proyecto requiere JavaFX SDK configurado como librería. Agrega estos argumentos de VM en las propiedades de ejecución del proyecto (NetBeans):
 
**Ruta para usar en mi casa:**
--module-path "C:\alexis_dieguez\java fx\javafx-sdk-21.0.11\lib" --add-modules javafx.controls,javafx.fxml
 
*Ruta para usar en el colegio:**
--module-path "C:\javafx-sdk-21.0.11\lib" --add-modules javafx.controls,javafx.fxml
